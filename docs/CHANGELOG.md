# Changelog

## 1.0.0 - 2026-08-15

- Initial public release candidate.
- Adds CSV/XLSX export for visible Dolibarr list rows.
- Adds admin configuration for formats, limits, CSV delimiter and UTF-8 BOM.
- Adds module permissions for export use and configuration.
- Documents GPLv3 licensing, publication status and third-party dependency posture.
- Expands the public GitHub README for release preparation.
- Validates CSV/XLSX export on Dolibarr 23.0.3/Linux and preserves raw JSON payload handling on the export endpoint.
- Sets DoliHub as the public publisher website while keeping GitHub for source code and technical support.
